MVP scope
⌘

Natural-language intake

Accepts a user ID and request through the chat API.

⇢

Policy-first routing

Keyword rules select a controlled workflow path; it is not an LLM planner.

▤

Document RAG

Chunking, Sentence Transformer embeddings, pgvector cosine search and source metadata.

▦

Constrained SQL

Single SELECT/CTE; allowlisted v_open_purchase_orders view; DB read-only transaction.

⇄

SAP OData read adapter

Mock PO read or configured bearer-token GET to PurchaseOrders.

⛨

Approval workflow

Validates supplier ID and INR amount, creates a pending PO proposal, supports approve/reject.

≋

Read-only MCP server

Publishes search_knowledge and run_readonly_sql tools. No write tools.

◷

Audit events

Stores request routes, retrieval/query activity and approval decisions in PostgreSQL.

⌁

Distributed tracing

OpenTelemetry instrumentation exported to Jaeger in Docker Compose.

Not implemented / not to be claimed

This is a production-oriented reference MVP, not a production-certified autonomous agent.
  • No autonomous multi-agent collaboration or LLM reasoning/planning loop.
  • No unrestricted SQL, writes, or broad SAP business-object coverage.
  • No real SAP PO creation: real writes are intentionally disabled.
  • No SSO/OIDC, RBAC groups, tenant isolation or document-level ACL enforcement.
  • No PDF/image OCR, email/Teams/Slack connectors, scheduler or workflow designer.
  • No built-in model evaluation suite, token-cost dashboard or business KPI analytics.
  • Routing is deterministic keyword classification and RAG returns retrieved excerpts rather than a generated synthesis.
